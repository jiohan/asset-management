# Phase 5-1: Transaction & Category Hooks 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 거래/카테고리 데이터를 Supabase에서 가져오고 저장하는 5개 커스텀 훅을 `src/hooks/`에 작성한다.

**Architecture:** 기존 `useLogin.js`, `useSignup.js`와 동일한 패턴을 따른다. 데이터 조회 훅(`useCategories`, `useTransactions`)은 `useEffect`로 마운트 시 자동 실행하며 `{ data, loading, error }` 형태를 반환한다. 뮤테이션 훅(`useCreateTransaction`, `useUpdateTransaction`, `useDeleteTransaction`)은 `{ 액션함수, loading, error }` 형태를 반환한다. Supabase RLS가 로그인된 유저 데이터를 자동 필터링하므로 쿼리에 `user_id` 조건을 별도로 추가할 필요 없다.

**Tech Stack:** React (useState, useEffect), Supabase JS Client (`src/lib/supabase.js`), AuthContext (`src/contexts/AuthContext.jsx`)

## 참고: 기존 패턴 (useLogin.js)

```js
import { useState } from 'react'
import { supabase } from '../lib/supabase'

export function useLogin() {
  const [loading, setLoading] = useState(false)
  const [error, setError] = useState(null)

  async function login({ email, password }) {
    setLoading(true)
    setError(null)
    const { error } = await supabase.auth.signInWithPassword({ email, password })
    setLoading(false)
    if (error) { setError('오류 메시지'); return false }
    return true
  }

  return { login, loading, error }
}
```

## Task 1: useCategories — 카테고리 목록 조회

**파일:**
- 생성: `src/hooks/useCategories.js`

**설명:** 컴포넌트가 마운트될 때 카테고리 전체(프리셋 + 내 커스텀)를 한 번 가져온다. Supabase RLS가 프리셋(user_id = NULL)과 내 커스텀(user_id = 로그인 유저)을 합쳐서 반환하도록 설정되어 있다.

- [ ] **Step 1: 파일 생성 및 코드 작성**

`src/hooks/useCategories.js`를 생성하고 아래 코드를 작성한다:

```js
import { useState, useEffect } from 'react'
import { supabase } from '../lib/supabase'

export function useCategories() {
  const [categories, setCategories] = useState([])
  const [loading, setLoading] = useState(true)
  const [error, setError] = useState(null)

  useEffect(() => {
    async function fetch() {
      setLoading(true)
      setError(null)

      const { data, error } = await supabase
        .from('categories')
        .select('*')
        .order('type')
        .order('name')

      setLoading(false)

      if (error) {
        setError('카테고리를 불러오지 못했습니다.')
        return
      }

      setCategories(data)
    }

    fetch()
  }, [])

  return { categories, loading, error }
}
```

## Task 2: useTransactions — 월별 거래 목록 조회

**파일:**
- 생성: `src/hooks/useTransactions.js`

**설명:** `month` 파라미터('YYYY-MM' 형식)를 받아 해당 월의 거래 목록을 날짜 내림차순으로 가져온다. 카테고리와 계좌 정보를 JOIN해서 함께 반환한다. `month`가 바뀔 때마다 자동으로 다시 조회한다.

- [ ] **Step 1: 파일 생성 및 코드 작성**

`src/hooks/useTransactions.js`를 생성하고 아래 코드를 작성한다:

```js
import { useState, useEffect } from 'react'
import { supabase } from '../lib/supabase'

export function useTransactions(month) {
  const [transactions, setTransactions] = useState([])
  const [loading, setLoading] = useState(true)
  const [error, setError] = useState(null)

  useEffect(() => {
    if (!month) return

    async function fetch() {
      setLoading(true)
      setError(null)

      // month = 'YYYY-MM' → 해당 월의 첫날~말일 범위 계산
      const [year, mon] = month.split('-').map(Number)
      const firstDay = `${month}-01`
      const lastDate = new Date(year, mon, 0).getDate()
      const lastDay = `${month}-${String(lastDate).padStart(2, '0')}`

      const { data, error } = await supabase
        .from('transactions')
        .select(`
          *,
          categories ( id, name, icon, type ),
          accounts ( id, name, color )
        `)
        .gte('date', firstDay)
        .lte('date', lastDay)
        .order('date', { ascending: false })
        .order('created_at', { ascending: false })

      setLoading(false)

      if (error) {
        setError('거래 내역을 불러오지 못했습니다.')
        return
      }

      setTransactions(data)
    }

    fetch()
  }, [month])

  // 외부에서 강제 새로고침이 필요할 때 호출
  function refetch() {
    setTransactions([])
    setLoading(true)
  }

  return { transactions, loading, error, refetch }
}
```

## Task 3: useCreateTransaction — 거래 추가

**파일:**
- 생성: `src/hooks/useCreateTransaction.js`

**설명:** 거래 1건을 transactions 테이블에 INSERT한다. INSERT 시 `user_id`를 함께 넣어야 RLS 정책을 통과한다. 저장 후 새로 저장된 행(카테고리·계좌 JOIN 포함)을 반환한다.

- [ ] **Step 1: 파일 생성 및 코드 작성**

`src/hooks/useCreateTransaction.js`를 생성하고 아래 코드를 작성한다:

```js
import { useState } from 'react'
import { supabase } from '../lib/supabase'

export function useCreateTransaction() {
  const [loading, setLoading] = useState(false)
  const [error, setError] = useState(null)

  async function createTransaction({ userId, categoryId, accountId, amount, type, note, date }) {
    setLoading(true)
    setError(null)

    const { data, error } = await supabase
      .from('transactions')
      .insert({
        user_id: userId,
        category_id: categoryId,
        account_id: accountId || null,
        amount: amount,         // 정수, 원 단위, 양수
        type: type,             // 'income' | 'expense'
        note: note || null,
        date: date,             // 'YYYY-MM-DD'
      })
      .select(`
        *,
        categories ( id, name, icon, type ),
        accounts ( id, name, color )
      `)
      .single()

    setLoading(false)

    if (error) {
      setError('거래를 저장하지 못했습니다.')
      return null
    }

    return data   // 저장된 거래 행 반환 (null이면 실패)
  }

  return { createTransaction, loading, error }
}
```

**사용 예시 (나중에 폼에서):**

## Task 4: useUpdateTransaction — 거래 수정

**파일:**
- 생성: `src/hooks/useUpdateTransaction.js`

**설명:** 기존 거래의 내용을 UPDATE한다. `id`로 행을 특정하고, 변경할 필드만 넘긴다.

- [ ] **Step 1: 파일 생성 및 코드 작성**

`src/hooks/useUpdateTransaction.js`를 생성하고 아래 코드를 작성한다:

```js
import { useState } from 'react'
import { supabase } from '../lib/supabase'

export function useUpdateTransaction() {
  const [loading, setLoading] = useState(false)
  const [error, setError] = useState(null)

  async function updateTransaction(id, { categoryId, accountId, amount, type, note, date }) {
    setLoading(true)
    setError(null)

    const { data, error } = await supabase
      .from('transactions')
      .update({
        category_id: categoryId,
        account_id: accountId || null,
        amount: amount,
        type: type,
        note: note || null,
        date: date,
      })
      .eq('id', id)
      .select(`
        *,
        categories ( id, name, icon, type ),
        accounts ( id, name, color )
      `)
      .single()

    setLoading(false)

    if (error) {
      setError('거래를 수정하지 못했습니다.')
      return null
    }

    return data   // 수정된 거래 행 반환 (null이면 실패)
  }

  return { updateTransaction, loading, error }
}
```

## Task 5: useDeleteTransaction — 거래 삭제

**파일:**
- 생성: `src/hooks/useDeleteTransaction.js`

**설명:** `id`로 거래 1건을 DELETE한다. 성공 시 true, 실패 시 false를 반환한다.

- [ ] **Step 1: 파일 생성 및 코드 작성**

`src/hooks/useDeleteTransaction.js`를 생성하고 아래 코드를 작성한다:

```js
import { useState } from 'react'
import { supabase } from '../lib/supabase'

export function useDeleteTransaction() {
  const [loading, setLoading] = useState(false)
  const [error, setError] = useState(null)

  async function deleteTransaction(id) {
    setLoading(true)
    setError(null)

    const { error } = await supabase
      .from('transactions')
      .delete()
      .eq('id', id)

    setLoading(false)

    if (error) {
      setError('거래를 삭제하지 못했습니다.')
      return false
    }

    return true
  }

  return { deleteTransaction, loading, error }
}
```
