# Phase 7+8 — 예산 설정 & 대시보드 설계

**날짜:** 2026-06-20  
**대상 Phase:** 7 (예산 설정), 8 (대시보드)  
**진행 순서:** Phase 7 완성 → Phase 8 진행

---

## 핵심 설계 결정

### 1. 예산 저장 방식
`profiles.monthly_budget` 대신 `budgets` 테이블로 완전 이관.

- `category_id = NULL` → 전체 예산
- `category_id = specific` → 카테고리별 예산
- `month` 컬럼(YYYY-MM)으로 월별 독립 관리
- 기존 `useMonthBudget` 훅(profiles 참조)은 새 훅으로 대체

### 2. 이전 달 자동 복사
해당 월 budgets 데이터가 없을 때 이전 달 값을 UI에 기본값으로 표시.  
실제 DB 저장은 사용자가 처음 수정할 때만 발생 (lazy save).  
첫 방문 시 페이지 상단에 배너: "이전 달 예산을 불러왔습니다."

### 3. 기타 예산 자동 계산
`기타 예산 = 전체 예산 − 설정된 카테고리 예산 합계`  
DB에 저장하지 않음. 항상 마지막 행에 위치, 수정 불가.  
기타 실제 지출 = 예산 미설정 카테고리들의 실제 지출 합산.

**엣지케이스:** 카테고리 예산 합계 > 전체 예산 → 기타가 음수  
→ 기타 행 빨간색 + 인라인 경고: "카테고리 예산 합계가 전체 예산을 초과했습니다"  
→ 자동 조정 없음, 사용자가 직접 수정

## Phase 7 — 예산 설정

### 데이터 레이어

새로 작성할 훅 4개:

| 훅 | 역할 |
|---|---|
| `useMonthBudgetData(month)` | budgets 테이블에서 전체 + 카테고리 예산 조회. 없으면 이전 달 복사 로직 |
| `useUpsertBudget()` | 예산 저장 — user_id + category_id + month 조합으로 upsert |
| `useDeleteCategoryBudget()` | 카테고리 예산 삭제 (전체 예산은 0원으로 설정, 삭제 없음) |
| `useMonthExpenseByCategory(month)` | 해당 월 카테고리별 실제 지출 집계 — Phase 8에서도 재사용 |

### 페이지 레이아웃

```
[ < 2026년 6월 > ]
[이전 달 예산을 불러왔습니다 ✏️]   ← 첫 방문 시만 표시

─────────────────────────────────
이번 달 예산
700,000원 중 540,000원 사용
████████████░░░░  77%

─────────────────────────────────

─────────────────────────────────
```

### 진행률 바 색상 규칙

| 사용률 | 색상 |
|---|---|
| 0~69% | 인디고 (안전) |
| 70~89% | 오렌지 (주의) |
| 90~99% | 빨강 (위험) |
| 100% 초과 | 빨강 + 행 배경 연빨강 하이라이트 |

### 편집 모달

**전체 예산 수정 모달**
- 트리거: 전체 예산 카드 [수정] 버튼
- 입력: 금액 (숫자 입력, 원 단위)
- 저장: useUpsertBudget — category_id = NULL

**카테고리 예산 추가 모달**
- 트리거: [+] 버튼
- 입력: 카테고리 드롭다운 (이미 예산 설정된 카테고리 제외) + 금액
- 저장: useUpsertBudget — 선택한 category_id

**카테고리 예산 수정/삭제 모달**
- 트리거: 카테고리 행 클릭
- 기존 금액 pre-fill
- [저장] + [삭제] 버튼
- 삭제: useDeleteCategoryBudget

### 연동

- 거래 추가/수정/삭제 → LedgerRefreshContext 통해 예산 진행률 즉시 갱신
- 카테고리 예산 변경 → 기타 금액 자동 재계산

### 서브태스크 순서

```
7-1  훅 4개 작성 (useMonthBudgetData, useUpsertBudget, useDeleteCategoryBudget, useMonthExpenseByCategory)
7-2  페이지 레이아웃 + 월 네비게이션
7-3  전체 예산 카드 UI
7-4  카테고리별 예산 리스트 + 기타 행
7-5  편집 모달 (추가/수정/삭제)
7-6  LedgerRefreshContext 연동 + 엣지케이스 처리
```

## Phase 8 — 대시보드

### 데이터 레이어

| 훅 | 출처 |
|---|---|
| `useTransactions(month)` | 기존 — 이번 달 수입/지출 합계 도출 |
| `useTransactions(prevMonth)` | 기존 훅 재사용 — 전월 수입/지출 합계 (요약 카드 델타 % 계산용) |
| `useAccountsWithBalance()` | 기존 — 순자산 합산 |
| `useMonthBudgetData(month)` | Phase 7 신규 — 전체 예산 + 잔여 |
| `useMonthExpenseByCategory(month)` | Phase 7 신규 — 도넛 차트 + 순위 리스트 + 전월 비교 |
| `useRecentTransactions()` | 신규 — 최근 10건, 월 필터 없음 |

전월 비교: `useMonthExpenseByCategory`를 현재 월 + 이전 월로 두 번 호출. 새 훅 불필요.

### 요약 카드 4개 상세

| 카드 | 데이터 | 부가 표시 |
|---|---|---|
| 총 수입 | 이번 달 income 합산 | 전월 대비 % (↑ 녹색 / ↓ 회색) |
| 총 지출 | 이번 달 expense 합산 | 전월 대비 % (↓ 녹색 / ↑ 주황) |
| 잔여 예산 | 전체 예산 − 총 지출 | 미니 진행률 바. 초과 시 카드 빨간색 틴트 |
| 순자산 | 모든 활성 계좌 잔액 합산 | 표시만 (전월 비교 없음) |

### 카테고리 지출 섹션

- 도넛 차트(좌) + 순위 리스트(우) 2컬럼 레이아웃
- 도넛 차트: Recharts `PieChart` + `Pie` + `Cell`
  - 중앙에 총 지출 금액 텍스트 오버레이 (CustomLabel or foreignObject)
  - Context7로 Recharts 최신 API 확인 후 구현
  - hover 시 slice 확대 + 툴팁 (금액 + 퍼센트)
- 순위 리스트: 지출 금액 내림차순 자동 정렬
  - 각 항목: 순위 번호 + 아이콘 + 카테고리명 + 금액 + 퍼센트 + 미니 진행바
  - 도넛 슬라이스 색상과 리스트 항목 색상 동기화

### 전월 비교 바 차트

- Recharts `BarChart` grouped
- X축: 카테고리명, Y축: 만원 단위
- 이번 달 바: 인디고. 이전 달 바: 회색
- 이번 달 > 이전 달인 카테고리: 이번 달 바를 주황으로 강조
- Context7로 Recharts BarChart grouped 최신 API 확인

### 최근 거래 리스트

- 최근 10건, 월 필터 없음
- 수입: 인디고 금액 / 지출: 기본 텍스트 / 이체: "→ 계좌명" 형태
- "전체 보기 →" 클릭 → `/ledger` 이동

### 서브태스크 순서

```
8-1  useRecentTransactions 훅 작성
8-2  페이지 레이아웃 + 월 네비게이션
8-3  요약 카드 4개 (전월 델타 포함)
8-4  카테고리 지출 도넛 차트 + 순위 리스트
8-5  전월 비교 바 차트 (Recharts BarChart grouped)
8-6  최근 거래 리스트
8-7  전체 연동 + Playwright 스크린샷 검증
```

## 디자인 원칙

- 각 UI 서브태스크 시작 전 `ui-ux-pro-max` 스킬로 컴포넌트 방향 확정
- 구현 후 Playwright MCP로 스크린샷 찍어 실제 화면 확인 후 완료 처리
- Recharts 사용 시 Context7 MCP로 최신 API 문서 참조
- 폰트: Pretendard Variable (한글 텍스트), JetBrains Mono (금액 숫자)
- 진행률 바, 차트 색상은 인디고(기본) → 오렌지(주의) → 빨강(위험) 일관 적용
- 금액 표시: `amount.toLocaleString('ko-KR') + '원'`
- 날짜 표시: `YYYY.MM.DD` 형식
