# Monimo — 기능 명세

## MVP 기능 (v1)

### 1. 인증 (Auth)

**회원가입**
- 이메일 + 비밀번호 입력
- Supabase Auth 처리
- 가입 완료 시 `profiles` 레코드 자동 생성

**로그인**
- 이메일 + 비밀번호
- 로그인 성공 → 대시보드로 이동
- 로그인 실패 → 에러 메시지 표시

**로그아웃**
- 헤더에서 로그아웃 버튼 → 로그인 화면으로 이동

---

### 2. 거래 입력 (Transactions)

**지출/수입 추가**
- 입력 항목:
  - 금액 (필수, 숫자만 입력, 원 단위)
  - 타입 (지출 | 수입 토글)
  - 카테고리 (필수, 목록에서 선택)
  - 날짜 (기본값: 오늘, 변경 가능)
  - 계좌 (선택, 등록된 계좌 중 선택)
  - 메모 (선택, 짧은 텍스트)
- 저장 후 목록 즉시 업데이트

**거래 내역 목록**
- 월 단위 필터 (기본: 이번 달)
- 날짜 내림차순 정렬
- 각 항목: 카테고리 아이콘, 이름, 금액, 날짜, 메모
- 항목 탭 → 수정/삭제 가능

**이체 추가**
- 입력 항목:
  - 출금 계좌 (필수)
  - 입금 계좌 (필수)
  - 금액 (필수)
  - 날짜 (기본값: 오늘)
  - 메모 (선택)
- 이체는 수입/지출 합계에 포함되지 않음

---

### 3. 월별 요약 대시보드 (Dashboard)

**상단 요약 카드**
- 이번 달 총 수입
- 이번 달 총 지출
- 잔여 예산 (= 월 예산 - 총 지출)
- 예산 초과 시 빨간색으로 표시

**카테고리별 지출 차트**
- 도넛 차트 (Recharts)
- 카테고리별 금액 + 비율 표시

**최근 거래 내역**
- 최근 10건 표시
- "전체 보기" → 거래 내역 페이지로 이동

**월 선택**
- 이전 달 / 다음 달 이동 버튼

---

### 4. 예산 설정 (Budget)

**월 전체 예산**
- 월별로 전체 예산 금액 설정
- profiles.monthly_budget 또는 budgets 테이블에 저장

**카테고리별 예산**
- 카테고리마다 개별 예산 설정 (선택)
- 현재 지출 / 예산 비율 바 표시
- 초과 시 빨간색 경고

---

### 5. 계좌 관리 (Accounts)

**계좌 추가**
- 이름 (예: 카카오뱅크 체크)
- 타입 (체크카드 | 신용카드 | 저축 | 현금)
- 색상 선택 (구분용)

**계좌 목록**
- 계좌별 카드 표시
- 계좌 잔액: 수입 합계 - 지출 합계 (이체 제외)

**계좌 편집/삭제**
- 이름, 타입, 색상 수정 가능
- 삭제 시 확인 다이얼로그

---

### 6. 카테고리 관리 (Categories)

**프리셋 카테고리**
- 기본 제공, 삭제 불가
- 지출 10개 + 수입 3개

**커스텀 카테고리 추가**
- 이름 + 이모지 입력
- 타입 (지출 | 수입) 선택

**커스텀 카테고리 삭제**
- 해당 카테고리의 기존 거래는 "기타"로 자동 이동

---
